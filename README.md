Saturday 21 November 2026 in one page: a broadsheet front page carrying 54
date-checked stories from nine regions — COP31 running past its deadline in
Antalya, three missiles downed over Riyadh, a magnitude 6.7 earthquake in
Peru's high Andes, and the rest of the day's world, every story dated
against its named source before it earned its place. `draw.py` paints the
whole page with PIL (no photographs); `entry.png` is its committed output;
`main.py` copies that file to the output path, byte for byte, on every run.

## Run it

```sh
python3 main.py
```
